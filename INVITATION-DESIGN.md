## Simple code entrance

The opening reuses the save-the-date monogram, exact script name and date styling, serif RSVP label and shared live Countdown component. After a recognized code, a full-screen ivory veil and large engraved brass lock appear. The vector lock has polished gold edges, symmetrical flourishes, a K&S medallion, and an inset keyhole. It settles into view, pauses, then the shackle lifts and slowly swings open. The open lock holds before the veil dissolves while the unlocked page fades in and an eased 1800ms scroll moves to the centered household greeting. The full sequence lasts about 5.2 seconds (3400ms for the lock, followed by the scroll). Invalid codes keep the page locked. Reduced-motion guests skip the overlay, fades, and animated scroll. Wheel, touch, pointer, or navigation-key input can interrupt the scroll. Timers, animation frames, and event listeners clean up on unmount. There is no envelope animation. Real invitation data is rendered only after server verification.

Before entry, wheel, touch, keyboard and inner-scroll attempts add a temporary gold outline/glow to the code field and update its help text. Typing clears the highlight. The locked root fills the viewport; on short or zoomed screens, only the introduction can scroll so the field remains reachable. A valid code removes the gate and restores normal page scrolling. Listeners and timers clean up on entry and unmount.
